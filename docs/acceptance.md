### Dependency deadlock regression (2026-10-24)

The root failure was representing local task-result dependencies as peer-comment subscriptions, plus presenting permanent configuration/expiry gates as ordinary waits. Typed local dependencies and explicit reply producers now cover these separately. Automated coverage includes original-session resume without comments, concurrent polls, pause/restart, disk-write failure/reopen, independent reporting failure, ambiguous/cross-project/self references, indirect cycles, failed dependencies, changes during async checks and changes before queued execution. Configuration changes report once; expired windows stay closed and globally visible. UI model tests distinguish a local dependency from a peer reply.

This is kernel/fixture validation, not a new real cross-account or production migration acceptance. Existing business tasks are not replayed by these tests.
