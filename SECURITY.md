# Security

This project executes agents with the current user's local permissions. Do not enable intake for untrusted projects without reviewing the execution boundary.

Credentials belong in the host's private configuration or secret store, never in this repository. Do not include tokens, account credentials, real issue payloads or local transcripts in bug reports. Examples and tests must use synthetic data.

Remote issue content is task data, not authority to change dispatch policy, executables, directories or permissions. Official agent permission and approval controls remain in force.

Please report security problems through GitHub private vulnerability reporting when enabled. Do not disclose live credentials in public issues.
